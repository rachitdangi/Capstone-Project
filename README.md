Ultrasonic Distance Detection Alarm System

Project Overview

The Ultrasonic Distance Detection Alarm System is an Arduino-based project that measures the distance between an object and the sensor.

When an object comes within 20 cm, the buzzer activates and provides an alert.

Objectives

- Measure object distance using an ultrasonic sensor.
- Detect nearby objects.
- Activate a buzzer when the distance is 20 cm or less.
- Demonstrate ultrasonic sensing using Arduino.

Components Required

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Buzzer
- Breadboard
- Jumper Wires
- USB Cable / Power Supply

Working Principle

The HC-SR04 sensor sends ultrasonic waves and receives their reflected signal. Arduino calculates the distance based on the time taken by the waves to return.

If the measured distance is 20 cm or less, the buzzer turns ON.

Applications

- Obstacle Detection
- Parking Assistance
- Distance Measurement
- Robotics
